# Separate Backend Resource Signals from Mode Semantics

Backend Initialization returns the complete bounded versioned Backend Resource Signal Contract: every Backend-owned metric field, unit, availability and quality meaning, conservative default threshold, and stable Contract identity. Every Backend Resource Sample binds that exact identity. The daemon binds it into the Environment Fingerprint, Resource Threshold Profile applicability, and audit evidence; missing, stale, or mismatched contracts and samples fail closed rather than using guessed semantics or a hidden side interface. Machine configuration may override threshold values through one atomic versioned Resource Threshold Profile, and every run records its effective values, Profile version, and Signal Contract identity. Execution Backends also declare per-operation Resource Impact with conservative peak memory-delta bounds. TurnVector retains one fixed action meaning for Normal, Guarded, StopAdmission, and Critical, so Backend evidence cannot silently redefine Scheduler safety behavior. Missing or stale required evidence immediately forces StopAdmission and escalates to Critical after a configured grace period.
