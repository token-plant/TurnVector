# Require Explicit Exclusive Mode for Non-Yielding Work

Work without a certified resumable Turn boundary cannot enter shared scheduling. A control-plane caller may explicitly request Exclusive Mode, which begins only after the current Turn reaches a synchronized safe boundary and shared dispatch pauses; accepted queues remain paused and new Admission and Residency Demand are rejected. One resource-bounded operation owns execution under a renewable Exclusive Lease while resource safety remains active. The mode has no total-duration guarantee, but the operation reaches an Exclusive Safety Point within a certified interval; Critical, lease disconnect, or lease expiry requests stop or rollback there. Cross-Model fairness, Interactive latency, and Progress Bound guarantees are suspended, and neither Backend nor Governor may enter the mode automatically.
