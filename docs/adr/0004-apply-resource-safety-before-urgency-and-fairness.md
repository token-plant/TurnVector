# Apply Resource Safety Before Urgency and Fairness

Every scheduling decision first removes work forbidden by the current ordered Resource Mode: Normal, Guarded, StopAdmission, or Critical. Guarded restricts Admission to resident Models under conservative budgets, prohibits memory-growing Residency Transitions, and starts cache and idle-Model reclamation; StopAdmission rejects all new Admission and Residency Demand while already accepted safe work continues; Critical additionally permits explicit failure and eviction at synchronized boundaries when lesser reclamation is insufficient. Restriction is immediate, recovery requires a safer exit threshold to hold for a dwell interval, and every stricter transition increments a Safety Generation that invalidates not-yet-started Turn Plans. Each transition produces a structured Governor Decision. Bounded Urgency and Model Weight apply only after these safety rules.
