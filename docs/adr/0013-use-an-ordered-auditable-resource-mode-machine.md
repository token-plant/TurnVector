# Use an Ordered, Auditable Resource Mode Machine

The Resource Governor exposes Normal, Guarded, StopAdmission, and Critical as an ordered safety state machine with a TurnVector-owned versioned action table. Each Execution Backend defines its resource-signal semantics and conservative default thresholds; machine configuration may override values in an atomic, versioned Resource Threshold Profile. Resource Evidence merges Device Executor-reported MLX allocator and cache values with daemon process footprint, available memory, swap, compressor, and pressure while retaining source provenance and freshness. The P-1B shared-host precheck may seed conservative defaults for the observed 256 GB host only; P-1B remains PENDING and neither certifies a 24-hour soak nor any 32, 64, or 128 GB system. Restriction takes effect immediately, while recovery or a less restrictive profile requires a safer exit threshold to hold for a configured dwell interval. Each stricter mode or profile increments Safety Generation, invalidating every not-yet-started Turn Plan from an older generation while allowing an in-flight Turn to reach its synchronized safe boundary. Stale evidence immediately forces StopAdmission; stale system evidence escalates to Critical after its grace period, while a Device Executor operation that misses its certified safe point triggers process-wide fail-stop through the Operation Watchdog. Every transition and action produces a structured Governor Decision.
