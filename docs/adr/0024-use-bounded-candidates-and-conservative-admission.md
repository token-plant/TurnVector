Later ordinary events cannot overtake it; later safety/cancellation work consumes that allowance, then coalesces or defers, or invalidates affected commitments and enters bounded fail-stop if deferral is illegal. Admission accepts only after checked `B + support_interference(H) + sequenced_event_interference(H) <= H`. `initialize`, result-classified `execute_turn`, `execute_exclusive`, `transition_residency`, and `shutdown` retain distinct startup, Turn, Exclusive, Residency, and shutdown classifications. An unclassified Backend operation, Core event, or lifecycle state fails the build instead of becoming free background work.

The entitlement vector also reserves request-specific capacity for terminal cancellation-membership-change formation. Removing a queued request from an existing candidate invalidates that membership and every not-started Plan containing it, then atomically rebinds, splits, merges, or closes their unstarted obligations and creates one terminal formation obligation for surviving members only when required. The cancellation, Receipt, Plan Rejection, local-stale, and Cost Profile Update transitions may only mark the next obligation pending, rebind its unstarted scope, or close it on typed impossibility. After the complete predecessor envelope ends, a standalone Core `begin_support` transition converts the pending obligation immediately before Candidate Formation or observation. Receipt Output Publication enqueue/discard therefore ends before observation begins, and no Result transition belongs to both an intrinsic/Turn envelope and its successor support envelope.

Candidate Formation is implemented by a private Model Planner Module that owns only same-Model feasibility, canonical Batch construction, and KV and Shape compatibility. Every eligible request must appear in a Work Candidate or receive one stable typed Candidate Exclusion. The Model Planner cannot consume Model Weight, Model Ledger, cross-Model service debt, relative priority, or urgency order. A private Turn Arbiter Module applies those global policies to the complete bounded result, freezes the selected membership in the Turn Plan, and never asks the Execution Backend to substitute work after selection.
