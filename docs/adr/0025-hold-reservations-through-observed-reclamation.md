# Hold Reservations Through Observed Reclamation

Admission creates a conservative request Resource Reservation in a capacity ledger rather than physically allocating maximum KV or output buffers. Separately, every model load requires a Governor-owned Residency Reservation derived from its Model Descriptor for shared weights and runtime residency cost; this cost never belongs to the first Warming request. Actual allocations consume the applicable reserved budget, and unused committed capacity cannot be admitted elsewhere while active. Each output-producing Turn also reserves its maximum visible output slots. At request termination or model unload, reservation capacity never physically allocated releases immediately; allocated memory becomes Pending Reclaim and remains charged until Worker allocator evidence plus process-footprint convergence proves reclamation. After Worker Exit, all possibly allocated Worker capacity remains behind a Worker Reclaim Barrier until the old process has exited, its Device Ownership Lease is released, and fresh system Resource Evidence establishes the new baseline; IPC EOF or a replacement Worker is insufficient. A Reclaim Stall triggers bounded cache clear and idle-Model reclamation plus Guarded Mode, then follows normal Resource Mode escalation without ever fabricating free capacity.
