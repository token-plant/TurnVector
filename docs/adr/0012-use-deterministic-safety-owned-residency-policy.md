# Use Deterministic Safety-Owned Residency Policy

The Resource Governor owns a deterministic Residency Policy independent of Scheduler fairness. Normal unload may select only Models with no accepted or runnable work, zero complete/partial Backend request ownership, and zero pending Request State Release; Model Weight never acts as a residency priority, and transition frequency and total Residency Service are bounded. Allocator/cache reclaim runs first as a bounded Reclaiming Residency Transition through the same serialized Backend operation; only later converged Resource Evidence proves reclaimed capacity. If cache and idle-Model reclamation remain insufficient in Critical, Eviction Rank explicitly orders affected Models; ties use estimated reclaimable bytes and stable Model ID. No Model is absolutely pinned. At the current Turn's synchronized safe boundary, Critical Eviction first terminally fails affected work, then obtains accepted Request Release Results consuming every request ownership, and only then unloads the Model. An untrustworthy release invokes process-wide fail-stop and forbids unload; the runtime never destroys a live handle, suspends affected work indefinitely, or waits for MLX to fail unpredictably.
