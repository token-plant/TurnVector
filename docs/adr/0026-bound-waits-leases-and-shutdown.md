# Bound Waits, Leases, and Shutdown

Preparing, Warming, and Output Backpressure have separate configured timeouts: Preparation Timeout fails a request that cannot obtain a Request Description, Residency Wait Timeout explicitly fails a Warming waiter, and persistent backpressure orders Cooperative Cancellation. None creates an inference SLO or automatic Exclusive entry. An Exclusive operation may have no total-duration limit only while a Control Plane Exclusive Lease remains renewed; disconnect or expiry cancels at the next certified Exclusive Safety Point. Terminal request status is retained only in count- and time-bounded Terminal Tombstones containing no output content. After eviction, an authorized owning connection can return stable Gone only for a current-instance Request ID at or below its connection-local Request High-Water Mark; this avoids an unbounded completed-request table without misclassifying foreign or unissued IDs. A build-time checked formula sums the worst-case required terminal Audit Records for every simultaneously live request, connection, control, and operation plus Critical, Device Executor Failure, repair, and shutdown, with one record per transition and no aggregation assumption; immutable binary maxima and state-machine tests prove the resulting Terminal Sequence Reserve. Ordinary work cannot consume it. Graceful Shutdown uses that reserve to reject new work, cancel all live work at safe points, perform Device Executor Shutdown on the owner thread, and strongly synchronize a Clean Shutdown Boundary. A matching Anchor slot completes `CLEAN_RELEASED`; if only that final Anchor write fails, the next Bootstrap recognizes the exact prior-session Boundary as a clean tail, writes no Crash Tail Boundary, and claims a new session without rewriting the old ownership state.
